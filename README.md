# Moduloom

One platform. Six ecosystems. Infinite combinations.

Moduloom is a modular, open-source application platform — Laravel/PHP
backend, React/TypeScript frontend, MariaDB, Tailwind. Instead of shipping
separate products for different needs, Moduloom ships one platform and
lets an installation grow by adding modules, never by migrating to a
different product.

This repository is pre-implementation. Before any code, three foundational
documents establish what's being built and why:

- [`MASTER_VISION.md`](./MASTER_VISION.md) — what this is, what it isn't,
  and the one idea the whole project exists to protect
- [`MASTER_ARCHITECTURE.md`](./MASTER_ARCHITECTURE.md) — the kernel
  invariants, schema, and technology decisions
- [`MASTER_ROADMAP.md`](./MASTER_ROADMAP.md) — phased build order and
  acceptance criteria for each phase

Status: private, pre-code. Not yet ready for public visibility.
